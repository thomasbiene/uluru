# Uluru — 550 Million Years in One Rock

An immersive, scroll-driven single page about Uluru, in Australia's Red Centre: its geology,
its colours, and the living culture of Anangu Country.

No framework, no build step — plain HTML, CSS and JavaScript.

## Run it

```bash
python -m http.server 4321
```

Then open <http://127.0.0.1:4321/>. Any static file server works; opening `index.html`
directly also renders, though the Google Fonts request needs a network connection.

## What's inside

| Path | |
| --- | --- |
| `index.html` | All content and structure |
| `styles.css` | Design system, layout and animation styles |
| `main.js` | Loader, reveals, sticky image sequence, horizontal timeline, counters, cursor |
| `assets/` | Photography (see credits below) |

Highlights: full-bleed hero, word-by-word statement reveal, count-up statistics, a pinned
image sequence, a scroll-driven horizontal timeline, an infinite gallery rail, and a
reduced-motion path.
